垃圾分类指南

2025-01-12 物业管理处

尊敬的业主：

为响应国家垃圾分类政策，提高小区环境质量，自2025年1月15日起，小区将实施新的垃圾分类标准。现将具体分类指南通知如下：

一、垃圾分类标准

小区将垃圾分为四大类：可回收物、有害垃圾、厨余垃圾和其他垃圾。

1. 可回收物（蓝色垃圾桶）

适宜回收和资源利用的垃圾，主要包括：

  • 纸张：报纸、杂志、图书、各种包装纸、办公用纸、广告纸、纸盒等（注意：纸巾和厕所纸由于水溶性太强不可回收）
  • 塑料：各种塑料袋、塑料包装物、一次性塑料餐盒和餐具、牙刷、杯子、矿泉水瓶、塑料玩具、塑料文具、塑料生活用品、洗发水瓶、塑料球、塑料梳子等
  • 玻璃：玻璃瓶和碎玻璃片、镜子、灯泡、暖瓶等
  • 金属：易拉罐、铁皮罐头盒、牙膏皮、废电池（可充电电池、纽扣电池除外）等
  • 布料：废弃衣服、桌布、洗脸巾、书包、鞋子等

2. 有害垃圾（红色垃圾桶）

含有对人体健康有害的重金属、有毒的物质或者对环境造成现实危害或者潜在危害的废弃物，主要包括：

  • 电池：纽扣电池、充电电池（如手机电池、铅酸电池）等
  • 荧光灯管：日光灯、节能灯等
  • 废药品及其包装物：过期药品、药品胶囊、药片、药品内包装等
  • 废油漆和溶剂及其包装物：废油漆桶、过期指甲油、洗甲水等
  • 废矿物油及其包装物
  • 废含汞温度计、废含汞血压计
  • 废杀虫剂及其包装

3. 厨余垃圾（绿色垃圾桶）

居民日常生活及食品加工、饮食服务、单位供餐等活动中产生的垃圾，主要包括：

  • 剩菜剩饭
  • 骨头内脏
  • 菜根菜叶
  • 果皮果核
  • 茶叶渣
  • 残枝落叶
  • 废弃食用油等

4. 其他垃圾（灰色垃圾桶）

除可回收物、有害垃圾、厨余垃圾以外的其它生活废弃物，主要包括：

  • 受污染与无法再生的纸张：卫生纸、纸巾、纸杯、纸尿片等
  • 受污染或其他不可回收的玻璃、塑料袋与其他受污染的塑料制品
  • 不可回收的果皮果核、灰尘渣土等
  • 废弃的陶瓷品、卫生间废纸、烟头、灰土、一次性餐具等

二、投放要求

  • 投放前，应将垃圾袋装化，袋口扎紧，避免垃圾洒落
  • 投放时，应按垃圾分类标志的提示，分别投放到指定的垃圾桶内
  • 投放后，应将垃圾袋投放到对应垃圾桶，保持垃圾桶周边清洁
  • 厨余垃圾应沥干水分后投放
  • 可回收物应尽量保持清洁干燥，避免污染
  • 有害垃圾应单独投放，避免混放

三、处罚规定

根据《城市生活垃圾管理办法》，对不按规定分类投放垃圾的行为，将处以50元以上200元以下罚款。

四、宣传培训

物业管理处将定期开展垃圾分类宣传培训活动，帮助业主掌握垃圾分类知识。如有疑问，可咨询物业客服热线：400-888-8888。
